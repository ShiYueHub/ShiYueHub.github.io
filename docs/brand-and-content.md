# ShiYue 品牌与内容草案

## 工作室简介

ShiYue 是 Seiko 的独立游戏工作室，专注于有温度的小世界：一封等待送达的信、一座亲手建起的营地、一盏夜色里不熄的灯。通过探索、建设和一点点故事，让平凡的行动成为值得记住的冒险。

短版：ShiYue，认真做游戏，也认真做梦。在小小的世界，遇见一点美好。

个人简介：你好，我是 Seiko，开发者，也是这些小世界的建造者。我喜欢把代码、画面和一点点故事放在一起，让一个念头慢慢变成可以游玩的世界。
